Biblioteca do clube — modelo das telas

Alvo aprovado da SPEC (../SPEC.md): se as duas divergirem, vale o modelo. Daqui se copia estrutura, ordem e texto, nunca CSS — as classes saem dos tokens e de ui/ (Cartao, Botao, Confirmacao, Campo, Selecao, EstadoVazio, MenuCabecalho, BarraProgresso). Capas, nomes e números são fictícios.
